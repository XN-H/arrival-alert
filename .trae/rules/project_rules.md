# 项目规则（project_rules.md）

> 本项目级规则优先级最高，每次对话自动生效。

【项目】「到站了」：给 **视障人士（及老年人）** 用的 **公交/打车到站语音提醒网页 Demo**，解决"乘坐公交常错过车次、现有地图只报下车不报上车"的问题。
- 赛题归属：TRAE on Campus @ 南方科技大学 · 无障碍公益黑客松
- 主打赛题：**赛题一「为过坎的人」**（面向残障群体与老年人）；地图能力复用 **赛题三** 橙光工具（survey-map）同款技术，可双投。
- 评审侧重：需求真不真 > 技术炫不炫；**当场跑得通**。

【交付形态】高保真可交互 HTML Demo，套一个"手机壳"边框，能点、能切页、能走完核心流程。
> 注意：**无需开发真微信小程序**，网页 Demo 即正式答卷。

【技术栈】
- 单个 `index.html` 入口 + 原生 JS（classic script，不用打包器/ESM）+ Tailwind（CDN）
- 地图：Leaflet 1.9.4（CDN）+ 高德地图瓦片（GCJ-02）
- 语音：浏览器 **Web Speech API**（`speechSynthesis`），零依赖、可离线
- 数据：本地 mock（`data/mock.js`），坐标统一用 GCJ-02 以对齐高德底图
- 不引入构建工具、不装依赖，浏览器直接打开即可运行

【目录】
- `/index.html` 入口（页面结构 + 视图切换）
- `/js/app.js` 逻辑（地图、语音、模拟调度、状态）
- `/data/mock.js` mock 数据（公交线路站点、打车车辆）
- 样式优先用 Tailwind 工具类，特殊样式内联

【无障碍加分项（必须体现）】
- 大字号、大按钮、单手可点（拇指热区）
- 语音播报（上车提醒 + 下车提醒 + 打车到站）
- 高对比度配色；关键动作有震动反馈（`navigator.vibrate`）
- 页面无控制台报错，断网时地图降级但语音/文字仍可用

【质量要求】
- 界面简洁大方，配色统一（主色橙，呼应"橙光队"），留有呼吸感
- 手机浏览器（375px 宽）打开不乱版
- 所有按钮/链接点了都要有反馈
- 表单为空提交、非法输入要有明确提示
- 页面无控制台报错

【协作习惯】
- 全程中文交流
- 改代码前先给计划，我确认后再动手
- 每轮只做我确认过的事，不擅自重构无关代码
- 改完列出改动文件清单，并说明每处改动原因
- 需求不清时先向我提问，不要自行假设
