# 到站了 · 视障出行语音提醒

> 给 **视障人士（及老年人）** 用的公交 / 打车到站语音提醒网页 Demo。
> 解决"坐公交常错过车次、现有地图只报下车不报上车"的问题。

**TRAE on Campus @ 南方科技大学 · AI 无障碍公益黑客松**
主打 **赛题一「为过坎的人」**；地图能力复用 **赛题三** 橙光工具（[survey-map](https://github.com/Wayhhow/survey-map)）同款技术，可双投。

---

## 一、核心亮点

| 亮点 | 说明 |
|---|---|
| 🔔 **上车也提醒** | 现有地图工具只做"下车提醒"，本作品补齐**上车提醒**（还有 N 站 → 车已到站请上车） |
| 🧭 **选站向导** | 公交页说「开始」后一问一答：问上车站 → 问下车站 → 播报确认 → 才出发，不用摸屏幕 |
| 🎙 **按住说话** | 长按音量键即可用语音操控，全程**不用看屏幕** |
| 🔊 **先报界面再听指令** | 按住时先播报"你在哪个界面、能做什么"，边播报边持续收听 |
| ✋ **说指令即打断** | 播报过程中直接说「开始」，立刻打断播报并执行，**并语音确认** |
| 🔁 **可连续说指令** | 按住期间持续识别，说完一句继续听，不用反复按 |
| 🖐 **松手停听** | 松开按键即停止收音；已触发的语音反馈会播完 |
| 🚨 **急停即用** | 音量− / `Esc` / 红色按钮，一键静音停一切，0.5 秒内可重新开始 |
| 📴 **可离线** | Tailwind、Leaflet 已本地化，语音用浏览器本地合成，**断网也能演示** |
| 🎨 **UI 可配置** | 所有视觉参数集中在 `UI_CONFIG`，方便后续换肤 |

## 二、快速开始

**方式一（最简单）**：双击 `index.html`，用 **Chrome 或 Edge** 打开。

**方式二（推荐，语音功能更稳）**：在项目目录起一个本地服务

```bash
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

> ⚠️ 两个前提：
> 1. **必须用 Chrome / Edge**（语音识别 `webkitSpeechRecognition` 只有它们支持）。
> 2. 首次使用请**允许麦克风权限**；若拒绝，语音功能会自动降级为按钮操作，不会报错。

## 四、怎么用

### 1. 外置演示控制台（点着演示）

| 按钮 | 效果 |
|---|---|
| 🚌 开始等公交 | 生成公交车 → 跳公交页 → 自动开始播报 |
| 🚕 开始打车 | 生成出租车 → 跳打车页 → 自动开始 ETA 倒计时 |
| ⏹ 停止 | 停止当前提醒 |
| ↺ 重置 | 全部复位回首页 |
| 🚨 急停 | 立刻静音 + 停识别 + 停车辆 |
| ❓ 帮助 | 播报"当前界面能说什么" |

### 2. 语音操控（核心）

**长按**手机壳右侧「按住说话」或者**按住键盘 `+`**：

```
按住 ──► 🔊 播报当前界面说明（同时进行）
       └─► 🎙 持续收听（按住期间一直识别）
              ├─ 听到「开始」等指令 ──► ✋ 立刻打断播报 → 执行 → 语音确认
              │                        （说完继续听，可连续下指令）
              └─ 松开 ──► 🛑 停止收音（已触发的语音反馈会播完）
```

### 3. 选站向导（公交页说「开始」后）

不用先在下拉框里选站，直接**一问一答**把上下车站定下来：

```
你说「开始」
      ↓
🔊 "开始设置。请问在哪一站上车？"
      ↓
你说「图书馆」        → 🔊 "上车站南科大图书馆。请问在哪一站下车？"
      ↓
你说「3号门」        → 🔊 "上车站南科大图书馆，下车站南科大3号门。确认吗？"
      ↓
你说「确认」          → 🚌 开始播报提醒
```

- 站名可以**简说**（"图书馆" 就能匹配 "南科大图书馆"）
- 匹配到多个会播报候选，你说"**第二个**"即可
- 也可以直接说"**第三个站**"用序号选
- 说错顺序会提示并**退回重选**上车站
- 说"**重来**"重新设置，说"**取消**"退出向导
- 打车页说「开始」保持**直接开始**（不需要选站）

### 4. 语音口令表

| 你说 | 效果 |
|---|---|
| 公交 / 打车 | 进入对应页面，并播报该界面导览 |
| **开始** | 公交页 → 进入**选站向导**；打车页 → 直接开始 |
| **直接开始** | 跳过向导，用下拉框当前选好的站直接出发 |
| 在**图书馆**上车 | 直接设置上车站（说简称即可），并语音确认 |
| 在**3号门**下车 | 直接设置下车站；顺序不对会被拦住并提示 |
| 换站 | 语音引导你重新选站（"请说：在某某站上车…"） |
| 打车去**体育馆** | 设置打车目的地，地图终点随之变化 |
| 还有几站 | 播报距目标站还有几站 |
| 帮助 | 重播当前界面的可用指令（向导中会念出全部站名） |
| 返回 | 回主界面 |
| 停止 | 停止提醒 |
| 急停 / 别说了 | 立即静音并停下一切 |

### 5. 播报时序（会听到什么）

**公交**（上车站 南科大1号门 → 下车站 南科大3号门）：

```
已开始提醒。37路，您将在 南科大1号门 上车，在 南科大3号门 下车。
还有 1 站到达上车站南科大1号门，请准备上车。
🔔 上车提醒：车已到站，南科大1号门，请上车，注意台阶。
还有 2 站到达下车站南科大3号门，请准备下车。
下一站南科大3号门，请准备下车。
🔔 到站提醒：已到达终点站南科大3号门，请下车，请注意脚下台阶。提醒结束，祝您出行顺利。
```

**打车**（接驾 → 上车 → 行程 → 到站）：

```
已开始提醒。去南科大图书馆。李师傅，白色比亚迪秦，车牌 粤B·D8888，预计 3 分钟到达上车点。
司机还有 2 分钟到达上车点。
司机还有 1 分钟到达上车点。
🔔 上车提醒：司机已到达上车点，车牌 粤B·D8888，请上车。
正在前往南科大图书馆，还有 1 分钟。
🔔 到站提醒：已到达目的地南科大图书馆，请下车。
```

> 「上车提醒」「到站提醒」这两句会以**最高优先级**播报（会打断其他语音），并触发手机震动。

### 6. 急停（三个入口）

`手机壳"急停"键` ｜ 键盘 `-` 或 `Esc` ｜ 控制台红色「🚨急停」

## 五、无障碍设计

- **大字号、大按钮**，拇指可单手点到的热区
- **全语音回读**：每次操作都有语音确认
- **震动反馈**：到站、上车等关键节点触发 `navigator.vibrate`
- **播报不打架**：队列 + 优先级（安全提醒可抢占，普通播报依次排队）
- **不会"自己听自己"**：播报期间做回声过滤，短指令不误伤
- **降级不崩溃**：不支持语音识别 / 无麦克风时，自动退回按钮操作

## 六、可配置项（给后续 UI 优化者）

所有视觉与节奏参数集中在 [js/app.js](js/app.js) 顶部的 `UI_CONFIG`：

```js
UI_CONFIG = {
  phone:  { width: 375, height: 840, radius: 44, bezel: 12 },  // 手机壳
  font:   { base: 16, title: 26, status: 24, btn: 17 },        // 字号
  color:  { brand: '#ea580c', ... },                          // 配色
  button: { radius: 18, padY: 16 },
  map:    { height: 200, busTickMs: 700, busFastTickMs: 150, ... },
  voice:  { beepGapMs: 110, rate: 1.2 },                      // 语速 1.2 倍
  anim:   { fast: '.18s', panDuration: 0.45 }
};
```

页面加载时会把这些值写入 CSS 变量（`--phone-h`、`--fs-base`、`--c-brand` …），因此：
**改 UI 只需动 `UI_CONFIG` + [css/theme.css](css/theme.css)，不需要碰业务逻辑。**

## 七、技术实现要点

| 模块 | 做法 |
|---|---|
| 地图 | Leaflet 1.9.4 + 高德瓦片（GCJ-02），无外网时降级为文字提示 |
| 车辆行驶 | 站点用 Catmull-Rom 样条加密成路径，并给中间点加横向弯曲，车辆**沿路径插值移动**（不是点间瞬移） |
| 语音播报 | Web Speech API（`speechSynthesis`），语速 1.2，队列 + 优先级调度 |
| 语音输入 | `webkitSpeechRecognition`，`continuous = true` 持续收听，支持打断 |
| 提示音 | WebAudio 现场合成"嘀/嘀嘟"，**不引外部音频文件**（保持离线可用） |
| 数据 | 全部本地 mock（`data/mock.js`），无需任何后端 |

## 八、2 分钟演示脚本

1. 点 **🚌 开始等公交** → 让评委听"还有 2 站到达…"→"**车已到站，请上车**"（这是现有工具没有的上车提醒）
2. **按住音量+** → 听它先播报界面，接着说 **"在图书馆上车"** → 听到"上车站已设为南科大图书馆"
3. 说 **"还有几站"** → 听进度播报
4. 说 **"打车去体育馆"** → 地图终点切换 → 说 **"开始"** → 听 ETA 与到站播报
5. 说 **"别说了"** 或按 `Esc` → **急停即用**，收尾

## 九、已知限制

- 真机**音量键**浏览器收不到按键事件 → 演示请用**屏幕上的音量键按钮**或**键盘 `+`/`-`**
- `webkitSpeechRecognition` 为实验性 API，仅 Chrome / Edge 支持
- **Chrome 限制**：语音合成（TTS）与语音识别会争抢音频系统，播报期间识别可能被中断。
  本作品的做法是**先开麦再播报**，且播报一结束就自动恢复收听；因此
  **按住后等界面说明念完再说指令最稳**，播报中途打断属于"尽力而为"
- 播报与说话同时进麦克风，极端情况下可能误识别；建议调低扬声器音量
- 地图瓦片来自高德，**演示时若无外网**只会显示线路与站点，不影响语音演示
